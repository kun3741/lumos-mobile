# Люмос для iOS

Це iOS-версія першого екрана лабораторної роботи 1 на SwiftUI. Вона показує той самий бриф, що й Android: назву, одне речення про застосунок, три заплановані екрани, джерело даних і майбутнє локальне налаштування.

Відкрийте `LumosMobile.xcodeproj` у Xcode на Mac, виберіть схему `LumosMobile` та симулятор iPhone, тоді натисніть Run. Мінімальна версія — iOS 16. Для запуску на фізичному iPhone в Xcode треба налаштувати власну команду підпису.

Поточний екран інформаційний. Каталог, деталі графіка, налаштування та підключення до REST API будуть додані в наступних роботах; серверну адресу потрібно буде опублікувати через HTTPS. Через відсутність macOS/Xcode в поточному середовищі збірку й запуск тут не перевірено.
