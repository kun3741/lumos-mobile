# Люмос · Android

**Люмос показує графіки відключень світла для обраної черги в одному місці.**

Перший екран є брифом лабораторної роботи 1. План застосунку: каталог регіонів, деталі графіка та налаштування черги й сповіщень. Локально зберігатимуться вибрані регіон і черга.

Джерело даних — власний сервер Люмос, що вже збирає графіки Івано-Франківщини, Львівщини та Волині. `GET /api/regions` повертає масив `regions` з полями `id`, `name` та `image_url`; запит не потребує OAuth або платного тарифу. Каталог не звертається до сайтів обленерго і витримав перевірку 10 одночасними запитами. Приклад запиту після запуску сервера: `http://localhost:8081/api/regions`.

Відкрийте цей каталог як проєкт в Android Studio й запустіть модуль `app` на емуляторі або телефоні. Потрібні JDK 17 та Android SDK 36. Тема потребує затвердження викладачем.

Версію для iOS плануємо реалізувати на SwiftUI з тим самим REST API; вибір регіону й черги зберігатиметься через UserDefaults.
