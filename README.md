# Люмос · Android та iOS

**Люмос показує графіки відключень світла для обраної черги в одному місці.**

Головний екран показує каталог регіонів, отриманий із сервера Люмос. Користувач фільтрує регіони за станом, відкриває деталі та може змінити порядок карток у налаштуваннях. Наступні екрани проєкту: деталі графіка та налаштування черги й сповіщень.

Джерело даних — власний сервер Люмос, що вже збирає графіки Івано-Франківщини, Львівщини та Волині. `GET /api/regions` повертає масив `regions` з полями `id`, `name` та `image_url`; запит не потребує OAuth або платного тарифу. Каталог не звертається до сайтів обленерго і витримав перевірку 10 одночасними запитами. Приклад запиту після запуску сервера: `http://localhost:8081/api/regions`.

Головний екран Android знаходиться у корені репозиторію: відкрийте його як проєкт в Android Studio й запустіть модуль `app` на емуляторі або телефоні. Потрібні JDK 17 та Android SDK 36. Перемикач «Призупинено» демонструє стан порожнього результату.

Починаючи з лабораторної роботи 4, вибраний фільтр зберігається у `RegionCatalogViewModel`. Екран отримує ViewModel через Compose `viewModel()`, читає закритий для зовнішнього запису `RegionCatalogUiState`, а зміни передає подією `onFilterSelected`. Тому вибір не скидається після повороту пристрою та перестворення Activity.

У лабораторній роботі 5 каталог і деталі розміщено в `NavHost`. Натискання на картку передає її `id` у маршрут `details/{regionId}`; навігаційний шар знаходить об’єкт і передає його екрану деталей. Деталі прокручуються, мають стрілку назад і показують окремий стан, якщо `id` не знайдено. Екрани отримують лямбди `onItemClick` та `onBackClick` і не працюють із `NavController` напряму.

У лабораторній роботі 6 додано маршрут налаштувань і параметр «Сортувати за назвою». Він зберігається у Preferences DataStore через єдиний делегат `preferencesDataStore` у `PreferencesDataStore.kt`. Репозиторій читає значення як `Flow<Boolean>` і змінює його в `suspend`-функції. Екран налаштувань і `RegionCatalogViewModel` підписані на те саме значення, тому каталог оновлюється автоматично. Для першого запуску використовується порядок за доступністю.

У лабораторній роботі 7 статичний `RegionCatalog.kt` видалено. `RegionCatalogViewModel` завантажує `GET https://lumos.foo/api/regions` через один екземпляр Retrofit під час відкриття каталогу та після зміни фільтра. DTO відповіді відокремлені від моделі застосунку, nullable-поля нормалізуються mapper-функцією, а під час запиту показується індикатор. API не потребує ключа. Мережеві зображення навмисно не показуються до лабораторної роботи 10.

Проєкт містить Gradle Wrapper 8.13. У IntelliJ IDEA встановіть плагіни Android та Android Design Tools, виберіть JDK 17 для Gradle JVM і синхронізуйте проєкт. Після підключення телефону з увімкненим налагодженням USB виберіть конфігурацію `app` і натисніть Run. Для перевірки збірки в Windows можна виконати `gradlew.bat :app:assembleDebug`; debug APK з'явиться в `app/build/outputs/apk/debug/`.

Перший екран iOS знаходиться у `ios/`: відкрийте `ios/LumosMobile.xcodeproj` у Xcode на Mac і запустіть схему `LumosMobile` на симуляторі iPhone або телефоні. Проєкт написаний на SwiftUI.

На Android уже реалізовано каталог зі справжніми даними API, деталі та постійне налаштування сортування для лабораторної роботи 7. Версія iOS поки містить перший екран-бриф.
