# Люмос · Android та iOS

**Люмос показує графіки відключень світла для обраної черги в одному місці.**

Головний екран показує каталог шести регіонів. Користувач натискає «Підключено» або «У розробці», після чого на екрані залишаються лише регіони з відповідним станом. Картки містять локальні ілюстрації, назву регіону, код, доступні черги та джерело графіка. Наступні екрани проєкту: деталі графіка та налаштування черги й сповіщень. Локально зберігатимуться вибрані регіон і черга.

Джерело даних — власний сервер Люмос, що вже збирає графіки Івано-Франківщини, Львівщини та Волині. `GET /api/regions` повертає масив `regions` з полями `id`, `name` та `image_url`; запит не потребує OAuth або платного тарифу. Каталог не звертається до сайтів обленерго і витримав перевірку 10 одночасними запитами. Приклад запиту після запуску сервера: `http://localhost:8081/api/regions`.

Головний екран Android знаходиться у корені репозиторію: відкрийте його як проєкт в Android Studio й запустіть модуль `app` на емуляторі або телефоні. Потрібні JDK 17 та Android SDK 36. Дані каталогу поки задані у `RegionCatalog.kt`, а зображення лежать у `res/drawable`. Перемикач «Призупинено» демонструє стан порожнього результату.

Починаючи з лабораторної роботи 4, вибраний фільтр зберігається у `RegionCatalogViewModel`. Екран отримує ViewModel через Compose `viewModel()`, читає закритий для зовнішнього запису `RegionCatalogUiState`, а зміни передає подією `onFilterSelected`. Тому вибір не скидається після повороту пристрою та перестворення Activity.

Проєкт містить Gradle Wrapper 8.13. У IntelliJ IDEA встановіть плагіни Android та Android Design Tools, виберіть JDK 17 для Gradle JVM і синхронізуйте проєкт. Після підключення телефону з увімкненим налагодженням USB виберіть конфігурацію `app` і натисніть Run. Для перевірки збірки в Windows можна виконати `gradlew.bat :app:assembleDebug`; debug APK з'явиться в `app/build/outputs/apk/debug/`.

Перший екран iOS знаходиться у `ios/`: відкрийте `ios/LumosMobile.xcodeproj` у Xcode на Mac і запустіть схему `LumosMobile` на симуляторі iPhone або телефоні. Проєкт написаний на SwiftUI.

На Android уже реалізовано фільтрований каталог зі станом у ViewModel для лабораторної роботи 4. Для наступних робіт залишаються деталі, підключення REST API та постійне збереження вибору; версія iOS поки містить перший екран-бриф.
